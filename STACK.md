# Content Hub: Tech Stack

2026-09-30 · Henry

Part of [PLAN.md](PLAN.md).

Rule for choosing packages: prefer first-party Laravel packages, then Spatie, then other widely used, actively maintained open source. Before installing, check the last release date and Laravel 13 support, and avoid stale or single-maintainer packages. Coding agents follow the same rule and should not hand-roll what one of these packages already does.

| Layer             | Choice                                                                                                                                  | Why                                                                                                                                                                     |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Framework         | Laravel 13 on PHP 8.3 or newer                                                                                                          | Current major release (March 2026), bug fixes until Q3 2027                                                                                                             |
| Starter kit       | Official Laravel React starter kit, generated with Teams                                                                                | Ships Inertia 3, React 19, TypeScript, Tailwind 4, shadcn/ui, login and team management; Teams become our workspaces                                                    |
| Auth              | Laravel Fortify (part of the kit)                                                                                                       | Email and password, password reset, optional two-factor authentication                                                                                                  |
| Database          | SQLite in WAL mode                                                                                                                      | Simple, one file, fits a single server                                                                                                                                  |
| Queue             | Laravel queues, database driver, on a separate SQLite file                                                                              | Background jobs for video and crawls without contending with the main database                                                                                          |
| Frontend          | Inertia 3, React 19, TypeScript, Tailwind 4, shadcn/ui                                                                                  | Your choice, and what the starter kit uses; add components with `npx shadcn@latest add`                                                                                 |
| Chat UI           | `useChat` from the Vercel AI SDK (`@ai-sdk/react`)                                                                                      | The Laravel AI SDK can stream in the Vercel AI SDK protocol                                                                                                             |
| Markdown display  | `react-markdown` with `rehype-sanitize`, remote images off                                                                              | Safe rendering of scraped and model text                                                                                                                                |
| AI                | Laravel AI SDK (`laravel/ai`)                                                                                                           | First party: agents, tool calling, structured output, streaming, conversation memory, queued agents, provider failover, images; supports OpenRouter for text and images |
| Video             | Own `VideoGenerator` interface over Laravel's HTTP client, run in queued jobs with polling                                              | The AI SDK has no video generation                                                                                                                                      |
| Scraping          | Own `FirecrawlClient` over Laravel's HTTP client (Firecrawl v2 API)                                                                     | The official PHP SDK requires Guzzle 7, but Laravel 13 ships Guzzle 8, so it cannot be installed; key in `FIRECRAWL_API_KEY`                                            |
| Uploads           | `spatie/laravel-medialibrary`                                                                                                           | Attaches files to models, with collections and conversions                                                                                                              |
| Typed data        | `spatie/laravel-data`                                                                                                                   | Typed context entries shared between the context builder and the chat page                                                                                              |
| Backups           | `spatie/laravel-backup`                                                                                                                 | Backs up the SQLite file and uploads, which covers the local disk risk                                                                                                  |
| Audit log         | `spatie/laravel-activitylog`                                                                                                            | Who did what in a workspace                                                                                                                                             |
| Filters           | `spatie/laravel-query-builder`                                                                                                          | Dashboard filters and sorting                                                                                                                                           |
| Video frames      | `php-ffmpeg/php-ffmpeg` plus the FFmpeg binary                                                                                          | Samples frames for media reading conversion                                                                                                                             |
| Markdown cleaning | Own `ContentSanitizer`: removes HTML comments, scripts, hidden elements, raw tags, invisible Unicode and `data:` URIs, then caps length | Safety layer 2 for scraped content; small enough that a package adds nothing                                                                                            |
| Quality           | Pest 4, Pint, Larastan                                                                                                                  | Tests, code style, static analysis; the kit's PHPUnit tests run under Pest unchanged                                                                                    |

Not needed for now: `spatie/laravel-permission` (all members share one role), Horizon (needs Redis), Reverb (start with Inertia polling for job progress), and Prism (it would duplicate the AI SDK).

Notes:

- **Workspace isolation:** a workspace is the kit's Team, so every workspace-owned table carries a `team_id`. All workspace routes sit under `/{current_team}` with scoped route bindings, so a record from another workspace resolves to a 404, and the kit's membership middleware returns 403 for a workspace you are not in. Tests cover both. Files live on a private disk and are served through an authorized route that checks the owning record's workspace.
- **SQLite settings:** `journal_mode` WAL, `synchronous` NORMAL, `busy_timeout` 5000. SQLite allows one writer at a time, so keep the queue and cache in separate files, and move to Postgres or Redis if write contention shows up.
- **Verified at install (2026-09-30):** all listed packages install on Laravel 13 (laravel-data 4.23, query-builder 7.3, medialibrary 11.23, activitylog 5.1, backup 10.3, php-ffmpeg 1.4, laravel/ai 1.0). The AI SDK does not expose model capabilities, so the app syncs OpenRouter's public model list into an `ai_models` table (`php artisan ai:sync-models`, also daily); it has input and output modalities, context length, tool support and prices. Video models only appear with `?output_modalities=video`, and their durations, aspect ratios and per-second price come from `/api/v1/videos/models`. MiniMax "H3" is `minimax/hailuo-3`, $0.13 per second, 5 to 15 seconds.
- **AI SDK limits found:** it cannot send video attachments to OpenRouter, so video context is always described from sampled frames. It does not pass through OpenRouter's billed cost, so spend is estimated from token counts and catalog prices (video uses the cost OpenRouter reports when the job finishes).
- **PHP binary:** use a PHP build that runs on your CPU. On this development machine (Intel i5-2500, no BMI2), the herd-lite static PHP crashes with an illegal instruction on some requests; the distro `/usr/bin/php8.4` works.
